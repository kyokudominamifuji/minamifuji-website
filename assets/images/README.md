# Image assets

画像は用途別に整理します。

- `profile/` : 公式プロフィール、TOP、宣材写真
- `flyers/` : 公演チラシ
- 今後、必要に応じて `stage/`（高座写真）、`logos/`（ロゴ）を追加

## ファイル名ルール

- プロフィール: `minamifuji-用途.拡張子`
- チラシ: `YYYY-MM-DD-公演名.拡張子`
- 英数字・ハイフンを基本にし、日本語やIMG_****のまま保存しない
